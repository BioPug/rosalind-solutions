# Rosalind Bioinformatics Solutions

This repository contains my Python solutions for problems from the [Rosalind](https://rosalind.info) platform, prepared as part of my portfolio.

## Repository Structure
* `stronghold/` - solutions for the 'Bioinformatics Stronghold' track.
* `utils/` - reusable helper modules.
